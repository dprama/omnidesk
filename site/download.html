First run

Open it the first time.

OmniDesk isn't signed with a paid certificate yet, so your computer asks once whether you trust it. You only do this once per computer.

Windows

  1. Open OmniDesk-…-win-x64.exe (or the Arm64 one).
  2. If SmartScreen says “Windows protected your PC”, click More info.
  3. Click Run anyway, then follow the installer.
  4. If Windows asks to let OmniDesk use the network, allow Private networks.

macOS

  1. Open OmniDesk-…-mac-x64.dmg and drag OmniDesk to Applications.
  2. Open Terminal and run this, exactly:
    xattr -dr com.apple.quarantine /Applications/OmniDesk.app
    It removes the “downloaded from the internet” flag from OmniDesk only.
  3. Open OmniDesk. Then go to System Settings → Privacy & Security and allow OmniDesk under Accessibility and Input Monitoring.
  4. Using Second screen? Also allow it under Screen Recording. Otherwise you can skip this.

Linux

  1. Make the AppImage executable: chmod +x OmniDesk-*.AppImage
  2. Double-click it, or run it from a terminal.

Pair your computers

  1. Open OmniDesk on both computers.
  2. Click Pair on one of them. It shows a 6-digit code.
  3. Type that code on the other computer. Done: push the cursor off the outer edge.
